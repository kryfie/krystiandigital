  _layouts/project.html

INSTALACJA
1. Otwórz lokalny folder repozytorium "krystiandigital" (GitHub Desktop → Repository → Show in Explorer).
2. Rozpakuj ZIP w dowolnym miejscu.
3. Skopiuj foldery assets/ i _layouts/ z ZIP do folderu repozytorium.
   Wybierz "Scal foldery" / "Zastąp pliki" dla wskazanych plików.
   Nie usuwaj pozostałych plików i katalogów.
4. GitHub Desktop → Commit to main → Push origin.
5. Po ukończeniu publikacji odśwież stronę Ctrl + F5.

ZMIANY
* Wyróżnione realizacje: całe zdjęcie widoczne w ramce, bez obcinania jego boków.
* Podstrona projektu: główne zdjęcie bez przycinania; kliknięcie powiększa.
* Dodatkowe zdjęcia w Pages CMS tworzą galerię z powiększeniem.
* Strzałki lewo/prawo przełączają zdjęcia, Esc zamyka, na telefonie działa przesuwanie palcem.
* Dla osób bez JavaScript zdjęcia nadal można otworzyć linkiem bezpośrednio.

UWAGA
Nie nadpisuj: _projects/ ani assets/images/projects/.
W tej paczce tych folderów w ogóle nie ma — wpisy, galerie i zdjęcia pozostają na GitHubie bez zmian.

Dalsze zdjęcia dodajesz jak dotąd: Pages CMS → Projekty / realizacje → wybrany projekt → Galeria dodatkowych zdjęć → Save.
